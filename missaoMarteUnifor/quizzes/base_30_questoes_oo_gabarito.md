# Gabarito e Explicações — Base 30 questões OO

Lista com a resposta correta e explicação breve para cada questão.

1. Resposta: Um molde (blueprint) para criar objetos.
   - Explicação: Classe define atributos e comportamentos de objetos.

2. Resposta: Ocultar detalhes internos e expor apenas o necessário.
   - Explicação: Encapsulamento protege estado e expõe interface controlada.

3. Resposta: private.
   - Explicação: `private` impede acesso direto fora da classe.

4. Resposta: Inicializa o objeto no momento da criação.
   - Explicação: Construtor prepara estado inicial ao usar `new`.

5. Resposta: 5.
   - Explicação: Construtor atribui `x = 5`; `getX()` retorna 5.

6. Resposta: Ana.
   - Explicação: Construtor define `nome` como "Ana" e getter retorna.

7. Resposta: Uma classe filha herda atributos e métodos da classe pai.
   - Explicação: Herança compartilha características entre classes.

8. Resposta: Au au.
   - Explicação: `Cachorro` sobrescreve `emitirSom()`; polimorfismo escolhe a subclasse.

9. Resposta: Permite tratar objetos de diferentes subclasses por meio do tipo da superclasse.
   - Explicação: Polimorfismo permite código genérico que opera sobre a superclasse.

10. Resposta: Verificar se um objeto é instância de uma classe/inteface.
    - Explicação: `instanceof` testa relacionamento de tipo em tempo de execução.

11. Resposta: Composição (ou agregação).
    - Explicação: Uma classe que possui outra tem relação de composição/agregação.

12. Resposta: 2.
    - Explicação: Duas strings foram adicionadas à lista.

13. Resposta: Atribui o parâmetro ao atributo da instância atual.
    - Explicação: `this` refere-se ao atributo do objeto atual.

14. Resposta: Uma interface define um contrato que classes podem implementar.
    - Explicação: Interfaces especificam métodos que implementações devem oferecer.

15. Resposta: `==` compara referências, `equals()` compara igualdade lógica.
    - Explicação: `==` verifica identidade; `equals()` verifica equivalência lógica.

16. Resposta: 3.
    - Explicação: Soma dos valores do loop: 0+1+2 = 3.

17. Resposta: Checked exceptions devem ser declaradas ou tratadas.
    - Explicação: Checked exceptions exigem `throws` ou `try/catch`.

18. Resposta: Uma subclasse fornece implementação específica para um método herdado.
    - Explicação: Override altera comportamento herdado em subclasse.

19. Resposta: Permitir acesso controlado a atributos privados.
    - Explicação: Getters preservam encapsulamento ao fornecer leitura controlada.

20. Resposta: B.
    - Explicação: `toString()` da subclasse `B` é chamado dinamicamente.

21. Resposta: Métodos com mesmo nome mas assinaturas diferentes na mesma classe.
    - Explicação: Overload diferencia métodos pelo conjunto de parâmetros.

22. Resposta: Maior flexibilidade e menor acoplamento entre classes.
    - Explicação: Composição favorece delegação sobre hierarquias rígidas.

23. Resposta: 150.0.
    - Explicação: Construtor inicializa o saldo e getter retorna o valor.

24. Resposta: Definir uma classe que pode ter métodos abstratos e não ser instanciada diretamente.
    - Explicação: `abstract` indica classe incompleta para ser estendida.

25. Resposta: Maior de idade.
    - Explicação: Condição `idade >= 18` é verdadeira.

26. Resposta: 0, 1 e 2.
    - Explicação: Loop executa para i = 0, 1, 2.

27. Resposta: Permite armazenar múltiplos passageiros dinamicamente.
    - Explicação: `List` é coleção dinâmica adequada para vários elementos.

28. Resposta: true.
    - Explicação: Instância criada é de `Professor`, portanto `instanceof` retorna true.

29. Resposta: Sobrescrever `equals()` e `hashCode()` de forma consistente.
    - Explicação: Implementação consistente é necessária para coleções e comparações.

30. Resposta: 10.
    - Explicação: Soma aritmética 4 + 6 = 10.
